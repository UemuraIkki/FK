# Pythonシミュレーション（D2Q9 LBMと3次元飛翔）

`knuckleball.py` は、NumPy、SciPy、Matplotlibで完結するブレ球（無回転サッカーボール）の流体・飛翔シミュレーションです。外部データや追加の計算パッケージを必要とせず、2次元円柱後流の格子ボルツマン計算、流体力抽出、フーリエ級数フィッティング、3次元飛翔運動方程式の数値積分、および可視化ダッシュボードの生成を一括して実行します。

## 物理モデルの解像と近似範囲

小規模な格子、低マッハ数、緩和時間 $\tau=0.53 \sim 0.6$ という制約のもとで、実球のレイノルズ数 $\text{Re} \approx 10^4 \sim 10^5$ を格子上で直接解像することはできません。単一緩和時間（BGK）モデルにおいて、格子単位の動粘性係数 $\nu_{\text{LB}}$、レイノルズ数 $\text{Re}_{\text{LB}}$、およびマッハ数 $\text{Ma}_{\text{LB}}$ は次の関係式で拘束されます。

```text
nu_LB = (tau - 0.5) / 3
Re_LB = U_LB * D_LB / nu_LB
Ma_LB = sqrt(3) * U_LB
```

本スクリプトの既定設定では、$\tau=0.53$、$U_{\text{LB}}=0.024$、$D_{\text{LB}}=36.0$ です。このとき格子レイノルズ数は $\text{Re}=86.4$、流入マッハ数は $\text{Ma}=0.0416$ となります。レイノルズ数は無次元量であるため、単位換算によって値を変更することはできません。$\tau=0.53$ かつ $U_{\text{LB}}=0.024$ を保ったまま $\text{Re}=100,000$ を直接解像する場合、円柱直径として約41,667セルの格子幅が必要になります。また、2次元円柱周りの流れでは、3次元球体特有の乱流境界層遷移や縦渦構造を物理的に表現できません。

こうした制約を踏まえ、本コードはシミュレーションを「解像された2次元流れ」と「経験的3次元飛翔モデル」の2段階に明確に切り分けています。

### 1. 解像された2次元流れ

不動の円柱断面周りの流れを、D2Q9 BGK格子ボルツマン法によって解きます。円柱表面には縫合線を模した非対称な凹凸を施し、幾何学的な対称性をあらかじめ崩しています。

- **流入境界**: Zou–He流速境界条件を適用した直後に、流入境界上のセルにのみ非平衡2次モーメント正則化（Latt et al., 2008）を適用します。再構築された密度、運動量、および非平衡応力を保持しつつ、低 $\tau$ 条件で不安定化しやすい高次運動モードの励起を抑えます。流体内部の衝突計算は通常の単一緩和時間BGKのまま変更しません。
- **流出・上下境界**: 流出境界では、ドメイン内へ流入する方向（W, NW, SW）の分布関数のみ法線方向ゼロ勾配で外挿します。上下境界は周期境界条件とします。
- **固体壁面と流体力抽出**: 障害物境界にはHalfway bounce-back方式を用います。円柱形状は階段状に格子へ配置されるため、形状表現には $O(\Delta x)$ の位置誤差を含みます。円柱が受ける流体力は、切断リンクにおける運動量交換 $\mathbf{F} = \sum_{\text{links}} 2 f_i^* \mathbf{c}_i$ を全ステップで集計して求めます。流体力抽出の処理に乱数は使用していません。

### 2. 経験的3次元飛翔モデル

2次元CFDで得られた流体力時系列から後流特性を抽出し、経験的な抗力・揚力モデルと組み合わせて3次元飛翔を計算します。

- **後流の同定**: ウォームアップ期間を除外した揚力係数の時系列から、パワースペクトル解析と有界最小二乗法によって渦放出周波数（ストローハル数 $\text{St}$）を同定し、3倍振動までのフーリエ級数を当てはめます。
- **位相の進行**: 飛翔中の後流位相は、無次元対流時間 $ds/dt = |\mathbf{v}| / D$ に従って進行します。
- **抗力危機と遅れ**: 球の基本抗力係数は、経験的な超臨界側混合率 $h$（遅延を伴う超臨界比率）に応じて亜臨界（既定値 0.48）と超臨界（既定値 0.20）の間を遷移します（実測された乱流境界層比率そのものではありません）。この混合率はレイノルズ数に対するロジスティック関数に向けて緩和時間（既定値 0.075秒）で追従し、抗力危機のヒステリシスと遷移遅れを表現します。実空間の臨界レイノルズ数は既定値で 300,000 です。球の抗力平均値には2次元円柱の平均抗力を用いず、2次元計算で得られた変動比率のみを球の基本抗力に乗じます。
- **不規則な横力**: 横力には、同定した周期揚力成分に加えて、オルンシュタイン＝ウーレンベック（OU）過程による低周波の不規則変動を加えます。横力の作用方向は瞬間速度ベクトルと常に直交するため、横力による仕事はゼロです（抗力は運動エネルギーを散逸させます）。
- **スピンの非考慮**: 本モデルは無回転のブレ球を対象としており、ボールの自転（スピン）やマグヌス効果、移動境界を伴う流体・構造の双方向連成計算は含みません。

飛翔計算は、目標距離（$x = 30\,\text{m}$）に達するか、ボール底面が地面に接触した時点（中心高度 $z \le D/2 = 0.11\,\text{m}$）で終了します。積分にはSciPyの `solve_ivp`（RK45）を使用します。

## 単位系と物理量の対応

格子単位と物理単位（SI単位）の変換関係は次のとおりです。

```text
dx = D_ball / D_LB              [m/cell]
dt = U_LB * dx / V_reference    [s/step]
```

この定義により、球の直径と代表対流時間は実空間と一致します。しかし、格子動粘性係数に対応する物理動粘性 $\nu_{\text{LB}} \Delta x^2 / \Delta t$ は、空気の動粘性係数（$1.5 \times 10^{-5}\,\text{m}^2/\text{s}$）よりも大幅に大きくなります。両者のレイノルズ数および粘性の値は、出力されるJSON診断ファイルに明記されます。

飛翔シミュレーションでは、実球の代表的な物理定数を使用します。

- ボール質量: $m = 0.43\,\text{kg}$
- ボール直径: $D = 0.22\,\text{m}$
- 代表投影面積: $A = \pi D^2 / 4$
- 空気の密度: $\rho = 1.225\,\text{kg}/\text{m}^3$
- 空気の動粘性係数: $\nu = 1.5 \times 10^{-5}\,\text{m}^2/\text{s}$
- 初期ボール中心高さ: $z_0 = 0.35\,\text{m}$（底面の初期地上高は 0.24 m）

アニメーションに表示される2次元流れの時刻と飛翔の時刻は、それぞれ独立した時間軸を持っています。ウォームアップ後のCFDデータ全体と、打ち出しから終点までの全飛翔軌道が動画の全体枠に割り当てられます。

## 数値的保護と検証基準

計算の破綻を隠蔽したまま不正な結果を出力しないよう、コード内には以下の検査機構が組み込まれています。

- **安定性判定**: 100ステップごとに密度と局所マッハ数を検査します。分布関数に非有限値（NaNやInf）が含まれる場合、流体セルの密度が $[0.8, 1.2]$ の範囲を逸脱した場合、または局所マッハ数が 0.1 以上に達した場合は、人工的な補正を行わずに例外を送出して計算を即座に停止します。
- **後流同定の検証**: ウォームアップ後の渦放出サイクル数が2未満の場合や、変動振幅が小さすぎる場合はフィッティングを中止します。また、サイクル数が4未満、揚力の決定係数 $R^2 < 0.75$、または前半後半のRMS比が定常範囲（0.7〜1.4）から外れる場合は、フィッティングが暫定的なものである旨の警告を表示します。

本実装は教育および可視化を主目的としたシミュレーションです。周期境界による流路狭窄効果、縫合線の格子解像度、流出境界までの距離、および力の統計量について、実機の空力予測を行うための系統的な格子・領域・時間収束性は検証されていません。特定のサッカーボールにおける抗力危機や不規則軌道の予測には、3次元乱流遷移モデルまたは実験風洞データが必要です。

## 実行方法

### 仮想環境の構築

```bash
# 仮想環境の作成とパッケージ導入（リポジトリルート FK/ で実行）
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### コマンド例

```bash
# 高速プリセットでの実行（240x120セル、48,000ステップ）（リポジトリルート FK/ で実行）
python knuckleball.py --quick

# 標準設定での実行（400x200セル、60,000ステップ）（リポジトリルート FK/ で実行）
python knuckleball.py

# 画面表示なし（Aggバックエンド）でGIF動画を出力（Pillowを使用）（リポジトリルート FK/ で実行）
python knuckleball.py --quick --no-show --save output/knuckleball.gif

# MP4動画の出力（PATHにffmpegが必要）（リポジトリルート FK/ で実行）
python knuckleball.py --no-show --save output/knuckleball.mp4

# 計算ステップ数とウォームアップ期間の延長（リポジトリルート FK/ で実行）
python knuckleball.py --steps 100000 --warmup 45000

# 数値不変量テストの実行（リポジトリルート FK/ で実行）
python -m unittest -v
```

### 主なコマンドライン引数

| 引数 | 既定値 | 説明 |
| --- | --- | --- |
| `--quick` | - | $240 \times 120$、直径24セル、48,000ステップの低解像度高速プリセット |
| `--nx`, `--ny` | 400, 200 | 格子サイズ（セル数） |
| `--steps` | 60000 | 総計算ステップ数 |
| `--warmup` | 24000 | 後流同定から除外する初期ステップ数（`--steps` 指定時は省略時その40%） |
| `--frames` | 160 | アニメーションの保存フレーム数 |
| `--seed` | 7 | 乱数シード（OU過程の初期乱数列） |
| `--diameter` | 36.0 | 円柱直径（セル数） |
| `--u0` | 0.024 | 流入流速（格子単位） |
| `--tau` | 0.53 | BGK緩和時間（0.53〜0.60） |
| `--seam-depth` | 0.035 | 縫合線の深さ（直径に対する比率、0〜0.08） |
| `--seam-angle` | 0.17 | 円柱の設置角度（ラジアン） |
| `--speed` | 25.0 | ボールの初速（m/s） |
| `--elevation` | 22.0 | 蹴り上げ角度（度、0〜80未満） |
| `--critical-re` | 300000 | 経験的抗力危機の中心レイノルズ数 |
| `--lift-gain` | 0.55 | 円柱揚力から球横力へのゲイン（0で横力を無効化） |
| `--wander-strength` | 1.4 | 低周波剥離揺らぎの強さ（0で低周波成分を無効化） |
| `--fps` | 24 | アニメーションの描画フレームレート |
| `--save` | - | 出力動画パス（`.gif` または `.mp4`） |
| `--output` | output/knuckleball | PNG画像、NPZ配列、JSON設定、CSVの保存プレフィックス |
| `--no-show` | - | GUIウィンドウを表示せずヘッドレス実行 |

## 出力ファイル

`--output output/demo` を指定した場合、以下のファイルが出力されます（`--output` の既定値は `output/knuckleball` であり、その場合は先頭が `output/knuckleball.*` となります）。

- `output/demo.png`: 最終状態のダッシュボード静止画
- `output/demo.npz`: サンプリングされた渦度・流速ベクトル配列、流体力、飛翔データ等
- `output/demo.json`: 格子設定、物性値、フィッティング結果、診断メタデータ
- `output/demo_forces.csv`: 全ステップの格子流体力・抗力・揚力係数時系列
- `output/demo_trajectory.csv`: 飛翔軌道の時間、座標、速度、対流時間、超臨界比率、空力係数時系列

## 単体テスト

`test_knuckleball.py` には以下の7つのテストケースが含まれており、`python -m unittest -v` で実行できます。

1. `test_zou_he_recovers_prescribed_velocity`: Zou–He正則化流入境界が指定速度を厳密に復元することの確認
2. `test_open_boundaries_preserve_uniform_flow`: 開放境界・周期境界において一様流が安定に維持されることの確認
3. `test_resting_seamed_obstacle_has_no_force`: 静止流体中で縫合線を持つ物体に余剰な流体力が発生しない静水圧不変量の確認
4. `test_link_force_equals_fluid_momentum_loss`: Halfway bounce-backによる反作用力が流体の運動量損失と一致することの確認
5. `test_fit_recovers_known_shedding_and_drag_harmonic`: 既知の正弦波データからストローハル数および高調波係数が正しく復元されることの確認
6. `test_lateral_force_does_no_work_and_rhs_is_deterministic`: 横力が速度と直交して仕事をせず、ODE右辺関数が決定論的であることの確認
7. `test_trajectory_terminates_at_target_and_ground`: 目標到達イベント（$x=30\,\text{m}$）および接地イベント（$z=0.11\,\text{m}$）で積分が正しく終了することの確認
